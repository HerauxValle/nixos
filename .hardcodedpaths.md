# Hardcoded paths

Files that reference an absolute or user-specific path (including via
`$HOME`) instead of resolving it relatively/dynamically. Kept as a running
list to revisit later, not because any entry here is currently broken.

- `Scripts/Casket/.test-bin/cas-test.sh` — `casketDir="$HOME/Dotfiles/Scripts/Casket"`.
  Needed because this script is wired onto PATH via
  `modules/packages/scripts/scripts.nix`'s `wrapScript`, which `cp -r`s the
  script's containing folder into the immutable Nix store and symlinks PATH
  to that copy — so the deployed script has no self-relative path back to
  the live `Casket/target/` build output; `$HOME` is the anchor back to the
  live repo.

- `Scripts/Managers/Hardlinks/main.py` — `STATE_DIR = Path("/home/herauxvalle/Dotfiles/Scripts/Managers/Hardlinks")`.
  Same class of issue as `cas-test.sh` above: once packaged by `flake.nix`
  in this same folder, the script runs from a read-only `/nix/store` copy,
  so `metadata.json`/`imports.json`/`.hlm_default` can't live next to the
  script anymore — hardcoded back to the live repo checkout instead.
