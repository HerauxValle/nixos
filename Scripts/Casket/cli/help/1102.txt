cas <vault> auth keyfile reset [location] [--keyfile path] [--pass "..."]

Overwrites the active keyfile with freshly generated bytes and re-keys
the vault's LUKS slot to match. IRREVERSIBLE -- the old key material is
gone the instant the new slot verifies; anything relying on the
previous bytes (backups, embedded copies elsewhere) stops working.

No location: in place, same name/path/form. Directory: keep the name,
new raw file there. File path: that becomes the new name.

EXAMPLES
  cas myvault auth keyfile reset
  cas myvault auth keyfile reset /mnt/usb/vaults/
