# 1.4.0

- changed: `passwd` moved to `auth passwd`. Old `passwd` now prints
  where it moved instead of running.
- added: `auth keyfile` — keyfile management, separate from `settings`
  (identity material, not a behavior toggle):
  - `move <location>` — relocate the active keyfile (copy, verify,
    delete original; never a bare rename, since the target is often a
    different filesystem)
  - `reset [location]` — overwrite with fresh key bytes and re-key the
    vault to match. Irreversible. Verification-gated by default.
  - `embed <carrier-file>` — copy the active keyfile's bytes into a
    trailer appended to any file, without touching its existing content
  - `extract <carrier-file> [location]` — recovery: pull key bytes back
    out of an embedded carrier into a standalone raw file
  - `strip <carrier-file>` — remove an embedded trailer, restoring the
    carrier's original content. Refuses (asks for typed confirmation)
    if the carrier is the vault's active keyfile
  - `activate <location>` — point the vault at a different keyfile file
    without re-keying; verifies it actually unlocks the vault first
- added: keyfiles can now be **embedded** — key bytes in a small tagged
  trailer appended to an arbitrary carrier file (a photo, a PDF,
  whatever), which keeps working as that file. Auto-detected everywhere
  a keyfile is read; existing raw keyfiles are unaffected.
