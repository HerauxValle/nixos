# 1.16.1

- Every command in the CLI (auth, backup, settings, sandbox
  namespaces/rootfs/cgroups/seccomp/network) is now routed through the
  `cli/registry.kdl`-driven dispatcher introduced in 1.16.0, not just the
  original network subtree. No command's behavior changed — this is
  purely how each one gets routed to its existing, unmodified handler
  function.
- `cas help <path>` is now tree-addressable to any depth for every
  command (`cas help settings security sandbox seccomp custom edit`,
  etc.), backed by one long-form help file per command. Falls back to
  the previous flat help table for anything genuinely outside the tree.
