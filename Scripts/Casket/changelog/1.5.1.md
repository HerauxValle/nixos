# 1.5.1

- changed: `info` and `settings verification state` output is now
  grouped into `[section]` headers (`[general]`, `[auth]`, `[settings]`,
  `[security]`, `[verification]`) instead of a flat list with a
  `verification-<feature>` name prefix to disambiguate — the section
  header does that job instead, so names stay plain everywhere.
- changed: `info` now shows passphrase state (required vs. bypassed)
  and the active keyfile's path plus whether it's a raw file or
  embedded in a carrier, under the new `[auth]` section — no new
  command or flag, just more of what `info` already reports.
