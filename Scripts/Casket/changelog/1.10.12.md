# 1.10.12

- added: `rootfs add <name> --tarball <path>` — local archive add path,
  validated with `tar -tf` before extraction.
- added: `rootfs remove <name>|<name,name,...>|all` — typed-confirm per
  environment (against the environment's own name, via new
  `prompt::confirm_named`), refuses while a `cas exec` session is live
  or if the target is the current default.
- added: `rootfs rename <old> <new>` — auto-updates the default symlink
  if it pointed at `<old>`.
- added: `rootfs default <name>|--clear|` — set/clear/show the
  `.rootfs.d/default` symlink `exec` falls back to.
- fixed: `rename` checked whether the target was the current default
  *after* already renaming its directory, when the symlink is already
  dangling and unresolvable — checked before the rename instead.

Verified live against a throwaway vault: full add/list/default/rename/
remove lifecycle, including the default-update-on-rename fix.
