# 1.7.0

- added: `settings security zeroize enable|disable` — scrubs the
  resolved passphrase and derived LUKS secret from memory the moment
  they go out of scope, instead of leaving them in freed-but-not-
  overwritten memory. Default on. Currently covers `secret::Secret`
  (the derived LUKS key returned by `get_secret`/`decode_autokey`) —
  the resolved plaintext passphrase itself isn't wrapped yet.
- added: `delete --shred` — overwrites the vault file with random data
  (3 passes) before removing it, instead of a plain unlink. Best-effort,
  not a guarantee: meaningful on a spinning disk, close to theater on an
  SSD (TRIM/wear-leveling mean the overwrite likely misses the original
  physical cells).
- added: tamper-evident metadata. `ransomwareProtection`,
  `verify_required`, and `zeroize` are now covered by an HMAC-SHA256
  keyed by the vault's own derived secret, refreshed whenever a write to
  one of them happens through a passphrase-verified path (piggybacks on
  the existing per-feature `verification` gate — if verification is off
  for a feature, its HMAC simply isn't refreshed on that write, same as
  before this existed). `cas <vault> open` checks it automatically: a
  mismatch resets those 3 fields to their most-protective values and
  warns, never a silent downgrade, and the open still proceeds (refusing
  would risk locking the owner out over a false positive). `cas <vault>
  tampered [--pass]` reports healthy/tampered/no-baseline on demand;
  `info --pass` reports it too, opt-in, without requiring a passphrase
  for `info` by default.
- added: `settings security bruteforceLockout enable|disable` — off by
  default. When on, `open` deletes the vault (no confirmation, no undo)
  after 10 consecutive wrong-passphrase attempts, tested via a dedicated
  `luks::test` check before the real unlock so an unrelated open failure
  (a busy mapper, etc.) never gets miscounted as a bad guess. A correct
  passphrase resets the counter. Threshold isn't configurable yet — 10
  is fixed. Enabling it prints a loud one-time warning.
