# 1.14.0

- added: `create --test` — marks a vault ephemeral. `close` (including
  via `toggle`) deletes the `.img` automatically right after a clean
  close, no confirmation prompt, since that's the point. A keyfile is
  never auto-deleted even if 2FA is enabled on a `--test` vault, since
  it could be shared with another, real vault. For throwaway testing
  only — there's no way to un-mark a vault once created.
