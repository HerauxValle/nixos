# 1.10.8

- added: liveness lockfile for `cas exec` sessions (`commands::exec::
  lockfile`) — `close` and `settings security sandbox disable` now
  refuse while a session is live, instead of unmounting/disabling out
  from under a running sandboxed process. Stale markers from a killed
  session are pruned automatically.
