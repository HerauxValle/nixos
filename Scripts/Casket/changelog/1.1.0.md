# 1.1.0

- added: `settings security ransomwareProtection` — locks `.casket/`
  (snapshots and anything else cas keeps inside a vault) to root-only,
  so a same-user attacker (e.g. ransomware running as you) can't read,
  create, or delete anything in it. Doesn't stop root or raw
  block-device access — only same-user attacks.
- added: `settings verification <feature>` — per-feature requirement to
  re-prove the vault's passphrase before toggling a protection, so
  plain `sudo` access alone can't disable one. Defaults on for
  `ransomwareProtection`, `backupAuto`, and `verification` itself.
  Disabling a currently-required verification (including on itself)
  still needs the passphrase.
- changed: in-vault snapshot storage moved from `.cas-snapshots/` to
  `.casket/snapshots/`, so `ransomwareProtection` can lock one shared
  root instead of a single-purpose folder. Existing vaults migrate
  automatically on next `open`.
- added: vault schema versioning (`meta/mod.rs` trailer gets a `_v`
  tag) and a migration system (`migrations/`) so future shape changes —
  to the metadata or the in-vault layout — don't break old vaults.
