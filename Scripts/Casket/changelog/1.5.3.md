# 1.5.3

- fixed: value columns in `info` (and any grouped `state` output) used
  a fixed width, so a long name (`ransomwareProtection`) and a short
  one (`2fa`) landed at different columns instead of lining up. The
  column width is now the longest name in the group plus 8 spaces,
  shared across `[settings]`/`[security]`/`[verification]` in `info`
  so the whole dump lines up, not just each section on its own.
  `[general]` and `[auth]` get the same treatment for their own fields.
