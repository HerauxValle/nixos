# 1.10.11

- added: `settings security sandbox rootfs add <name> --preset <distro>
  [<version>]` — live tarball download + checksum verify + extract into
  `.rootfs.d/<name>/base/` (`upper/` created empty alongside), writes
  `.casket-source`. `ureq` added for the fetch.
- added: `docs/rootfs-registry.md` — registry format, what's currently
  supported per distro, how to add/verify a new one.
- fixed: the registry's original alpine/ubuntu/debian URL assumptions
  were wrong (verified against the real endpoints while implementing
  this) — Alpine has no fixed "latest" filename (now resolved via its
  real machine-readable release index instead, which also carries the
  checksum), Ubuntu's assumed "current" alias doesn't exist (`add
  --preset ubuntu` with no version now refuses cleanly instead of
  hitting a 404), and both use `amd64`/`arm64` arch naming, not
  `x86_64`/`aarch64` (new `arch_names` override field).

Verified live: `rootfs add <name> --preset alpine` (no version) against
the real network — resolved 3.24.1 via the index, downloaded, checksum
verified, extracted, correctly chowned to the real user.
