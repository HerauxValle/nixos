# 1.5.0

- added: `state` as a global third verb everywhere `enable|disable`
  already existed — `settings encryption state`, `settings 2fa state`,
  `settings backup auto state`, `settings security <feature> state`,
  `settings verification <feature> state`, and `settings verification
  state` (all gated features at once). Every state line prints the same
  format: `<name>   enabled|disabled`.
- changed: `info` now rolls up every registered setting's state
  (encryption, 2fa, security features, backupAuto, verification per
  feature) instead of just 2FA. Settings walk the same `Feature`
  registry `state` uses, so a new setting added to `FLAT_FEATURES` or
  `security::FEATURES` shows up in both `state` and `info` with no
  extra wiring.
