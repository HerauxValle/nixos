# 1.6.0

- added: colored output, on by default whenever stdout is a real
  terminal, `TERM` isn't `dumb`, and `NO_COLOR` isn't set. One fixed
  palette everywhere — `[✓]` green, `[x]` bold red, `[!]` yellow, `[i]`
  cyan, `[section]` headers bold cyan, setting/field names dim,
  `enabled`/`disabled` green/red — not per-command ad hoc color choices.
  `src/color.rs` is the single place that decides whether color is on
  and owns the whole palette; every other module calls into it instead
  of hardcoding an ANSI code.
- changed: `Ctx::log` (the function every `logf!` call already runs
  through) auto-colors any `[✓]`/`[x]`/`[!]`/`[i]` marker at the start
  of a line, so the ~70 existing call sites across the codebase got
  colored output without editing each one individually.
