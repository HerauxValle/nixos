# 1.10.9

- added: `settings security sandbox rootfs list` — lists named rootfs
  environments for `exec --rootfs <name>`. `.rootfs.d/` is created
  lazily as a real btrfs subvolume on first use, chowned to the real
  user, sibling to `.casket/` (not nested — see `config::ROOTFS_DIR`'s
  doc comment). Empty for now; `add`/`update`/`remove`/`rename`/
  `default` come in later slices.
