# 1.1.1

- fixed: a vault with a metadata trailer that fails to parse (corrupt,
  or a future format this build doesn't understand) used to be treated
  identically to "no metadata at all", so the next write would silently
  overwrite real settings with defaults. Now backs up the raw trailer
  bytes next to the vault and warns loudly instead.
- fixed: `Meta`'s fields didn't tolerate being missing (a field added in
  a newer build would fail to parse entirely on an older vault's
  trailer, wiping keyfile/encryption state on next read). All fields
  now default cleanly when absent.
