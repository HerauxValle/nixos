# 1.10.5

- added: `settings security sandbox namespaces set|enable|disable|state`
  — which Linux namespaces `exec` will isolate (mount/pid/uts/ipc/user/
  net). Default is every namespace except `net`. `user` can't be
  disabled — always active regardless of this setting.
