# 1.10.3

- added: `btrfs::subvolume_create`/`is_subvolume`/`is_readonly`/`set_readonly`
  wrappers
- changed: schema v1 -> v2 — `.casket/` is now migrated from a plain
  directory into a real btrfs subvolume on next open, so a parent-level
  snapshot automatically skips its contents (groundwork for the
  upcoming sandbox rootfs feature's own no-backup-by-default behavior).
  Idempotent, layout-only, runs once per vault. Existing snapshot
  subvolumes under `.casket/snapshots/` are relocated whole (never
  walked into) to sidestep the recursive self-nesting that whole-mount
  snapshots produce over time.
