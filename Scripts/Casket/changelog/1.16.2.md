# 1.16.2

- `cas debug parse-cli`'s Ignored-check no longer hardcodes a list of
  every domain module's Rust path. Each command module now
  self-registers its own known ids at its own definition site (via the
  `inventory` crate); the checker just asks "what registered itself",
  discovering every domain automatically. Moving, renaming, or nesting a
  command module differently no longer requires updating any aggregator
  file — `cli/registry.kdl` remains the only file touched for CLI shape
  changes, and now that holds for the Rust side's internal wiring too.
  Purely internal; no user-visible change.
