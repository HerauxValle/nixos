# 1.10.6

- added: `src/sandbox/` -- the real namespace/pivot_root/proc/dev/harden/
  reap primitives for the upcoming `cas exec` sandbox, plus a standalone
  `sandbox_poc` dev binary exercising them against a plain directory
  (not wired to any vault yet)
- added: `--debug` -- global flag, prints `[debug]`-prefixed diagnostic
  tracing (`ctx.debug`/`debugf!`), silent unless passed
- fixed: a real bug in the PID1 reap-loop's cleanup: `kill(-1, SIGKILL)`
  ("every process I have permission to signal") was reachable from a
  process that was never actually a member of the isolated PID
  namespace, broadcasting to the real host session instead of a
  sandboxed subtree. Now requires an explicit fork into the namespace
  first, and refuses to fire at all unless `getpid() == 1`.
