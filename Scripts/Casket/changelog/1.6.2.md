# 1.6.2

- fixed: `info`'s `keep <N>` line was indented 2 extra spaces beyond
  every other field (to nest it visually under `backupAuto`), but was
  padded to the same column width as everything else — so its value
  landed 2 characters to the right of the rest of the output. The extra
  indent now shrinks the padding width to compensate.
- added: `[cas] ...` progress lines (used across ~10 commands —
  `create`, `open`, `close`, `resize`, `rename`, `2fa enable/disable`,
  `auth passwd`, `auth keyfile reset`, ...) are now colored, along with
  the `[1/3]`/`[2/3]`/`[3/3]`-style step markers `luks.rs` prints during
  a slot cycle. Both had been completely uncolored.
- added: `cas list`'s `STATE`/`2FA` columns are now colored green/red
  like every other enabled/disabled-shaped value in the CLI, instead of
  being the one table left entirely plain.
- added: `backup list`'s `auto-backups [enabled/disabled, keep=N]`
  status word is now colored green/red to match.
