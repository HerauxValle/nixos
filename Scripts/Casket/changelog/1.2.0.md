# 1.2.0

- changed: every persistent per-vault toggle moved under `settings`,
  all sharing `enable|disable`:
  - `encryption on|off` → `settings encryption enable|disable`
  - `2fa on|off` → `settings 2fa enable|disable`
  - `backup auto enable|disable|keep <N>` → `settings backup auto ...`
  Old top-level `encryption`/`2fa` and `backup auto` now print where
  they moved instead of running.
- changed: `backup` is data operations only now (`create`/`list`/
  `restore`/`delete`) — the auto-backup on/off policy is a setting, not
  a data operation, so it lives at `settings backup auto`.
- added: `settings/` is a small registry (`Feature { name, set }`)
  instead of hand-written match arms, so a new toggle is a new file
  plus one array entry.
