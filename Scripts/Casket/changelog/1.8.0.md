# 1.8.0

- added: `settings security bruteforceLockout enable [--threshold N]` and
  `settings security bruteforceLockout threshold <N>` — the wrong-
  passphrase-attempt limit before `open` deletes the vault is now
  configurable (was fixed at 10). Shows up in both `state` and `info`.
