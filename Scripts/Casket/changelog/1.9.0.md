# 1.9.0

Start of a security-feature batch — see 1.9.x for the individual pieces
(`fileIntegrity` and its container-migration engine).

- added: `src/migrate.rs` — a pure-Rust recursive tree copy + content
  verify (SHA-256 per file, not just size/mtime), with a live progress
  bar (percentage, byte counter with auto-picked unit, current
  filename). Not exposed through any command yet — internal groundwork
  for the container migration `fileIntegrity` needs — but it's real,
  tested capability (copy, verify, resume-skip-on-rerun, and
  tamper-detection all covered by an automated test) rather than a
  placeholder.
