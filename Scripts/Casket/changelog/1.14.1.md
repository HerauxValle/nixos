# 1.14.1

- fixed: a `--test` vault that was created but never opened wasn't
  deleted by `close` — the "already closed, nothing to do" fast path
  returned before the ephemeral-delete check ever ran. `create --test`
  immediately followed by `close` (no `open` in between) now correctly
  deletes the `.img`.
