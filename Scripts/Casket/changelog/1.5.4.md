# 1.5.4

- fixed: `info`'s column width was computed separately per group of
  `line()`/`kv_line()` calls — `[general]`/`[auth]` got their own width,
  `[settings]`/`[security]`/`[verification]` got another — so the value
  column still didn't line up between them. Now computed once from
  every name in the entire `info` output, so all five sections share
  one column top to bottom.
