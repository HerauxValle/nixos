# 1.16.0

- added: `cas debug parse-cli` — a new bare, no-vault-needed command
  (same shape as `list`/`quit`) that dumps the CLI's compiled-in tree as
  ASCII and reports two consistency problems: `Ignored` (a declared
  command with no wired Rust handler behind it — would otherwise be a
  silent no-op) and `Duplicate` (two commands sharing the same internal
  id — would otherwise silently misdispatch to whichever one happened to
  be checked first). Fully separate from the pre-existing `--debug` flag.
- Underlying architecture: the CLI's shape (names, nesting, help text,
  arg/flag schema) now lives in `cli/registry.kdl`, compiled into the
  binary at build time. A stable numeric id on each leaf is the only
  thing binding a KDL node to its Rust handler — renaming, moving, or
  rewording a command in the KDL file never requires touching Rust.
  `Duplicate` ids are enforced at startup (not just advisory in
  `debug parse-cli`): a collision now fails loud immediately rather than
  silently misrouting.
