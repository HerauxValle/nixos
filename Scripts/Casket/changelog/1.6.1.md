# 1.6.1

- fixed: `color::auto` only ever colored one marker in a whole multi-line
  string (whichever it found first), so any output with more than one
  line — every static help page — came out completely uncolored beyond
  its very first line. Now colors every line independently.
- fixed: static help pages had no coloring at all — `USAGE`, `ACTIONS`,
  `GLOBAL`, `OPTIONS`, `EXAMPLES`, `TYPICAL FIRST USE`, and table header
  rows (`cas list`'s `NAME SIZE STATE PATH`) are now recognized as bare
  ALLCAPS headers and colored, without touching any of the actual help
  text content.
- added: `WARNING:` is now colored yellow like `[!]`, everywhere it
  appears (e.g. `settings encryption disable`'s help page).
- added: plain data values with no enabled/disabled meaning (vault
  path, size, keyfile path, `keep <N>`, etc.) are now colored yellow —
  previously `info`'s `[general]`/`[auth]` fields and `keep` were left
  uncolored while everything else in the same output was.
- fixed: `info`'s `keep <N>` line under `backupAuto` was hand-formatted
  with fixed spacing instead of going through the shared column-width
  formatter, so it neither lined up with the rest of the output nor
  picked up any coloring. Now uses the same `kv_line` every other field
  does.
